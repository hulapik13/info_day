# ⛽ Бензин-радар — живая карта АЗС Москвы

Карта всех АЗС Москвы и области (данные OpenStreetMap) + **живые отметки** «есть/нет
бензина, какая очередь», которые ты и друзья ставите в реальном времени. Отметка
одного видна всем мгновенно.

- Карта с реальными улицами (Leaflet + тайлы OSM) — работает на GitHub Pages.
- Общая база отметок — Firebase Realtime Database (бесплатный тариф Spark).
- Друзьям нужна только ссылка. Никакой установки, никакого включённого компа.

## Шаг 1. Хостинг — уже готов
Сайт лежит на GitHub Pages этого репозитория. URL Pages показан в Settings → Pages.

## Шаг 2. Подключить базу отметок (Firebase, ~3 минуты, бесплатно)
1. Зайди на https://console.firebase.google.com → **Add project** (любое имя, Google
   Analytics можно выключить).
2. В проекте: **Build → Realtime Database → Create Database** → регион **europe-west1**
   → **Start in test mode** (или locked, см. правила ниже).
3. **Project settings (⚙️) → General → Your apps → </> (Web)** → зарегистрируй
   приложение → скопируй объект `firebaseConfig`.
4. Впиши значения в файл `config.js` этого репозитория (`apiKey`, `authDomain`,
   `databaseURL`, `projectId`) и запушь. Всё — карта оживёт.

### Правила безопасности Realtime Database
В test mode запись открыта всем на 30 дней. Чтобы держать только ветку отметок
открытой (достаточно для инструмента «для своих»), в **Realtime Database → Rules**:
```json
{ "rules": { "reports": { ".read": true, ".write": true } } }
```
Это значит: кто угодно со ссылкой может читать и писать отметки. Для друзей норм.
Если захочешь строже — добавим вход по анонимной авторизации Firebase.
