# ⛽ Бензин-радар — живая карта наличия топлива (Москва и область)

Живой сайт: **https://hulapik13.github.io/info_day/**

Карта всех АЗС Москвы и МО с автоматическим статусом наличия бензина, очередями
(в машинах), лимитами по литрам и ценами. Данные агрегируются из нескольких
открытых источников + слой отметок «для своих». Работает целиком на бесплатной
инфраструктуре GitHub, без своего сервера.

## Как устроено (архитектура)

```
[gdebenz.org]  [gdebenzi.ru]  [азсрадар.рф]        (открытые API наличия)
      \             |             /
       \            |            /
   .github/workflows/poll.yml  ← GitHub Actions, раз в ~5 мин
       (curl трёх источников)
              |
          merge.py             ← слияние по координатам: «самое свежее по АЗС»
              |
          live.json            ← общий снимок (коммитится в репозиторий)
              |
   GitHub Pages (index.html + app.js)   ← статичный сайт, читает live.json
              |
        [ браузер: Leaflet-карта ]  +  Firebase Realtime DB (слой отметок друзей)
```

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | разметка страницы, стили, мобильная вёрстка, нижняя шторка |
| `app.js` | вся логика карты: загрузка `live.json`, покраска по статусу, фильтры, шторка АЗС, слой друзей (Firebase), сохранение фильтров |
| `merge.py` | агрегатор: сопоставляет станции 3 источников по координатам, выбирает свежайший статус, собирает очередь-в-машинах, лимиты, цены, метки источников и время обновления |
| `.github/workflows/poll.yml` | GitHub Actions: каждые ~5 мин тянет 3 источника, гоняет `merge.py`, коммитит `live.json`; самоперезапуск через секрет `PAT` |
| `live.json` | последний агрегированный снимок (генерируется парсером) |
| `config.js` | конфиг Firebase (публично-безопасный) для слоя отметок друзей |
| `vendor/` | библиотека карты Leaflet (локально, без CDN) |

## Источники данных

- **gdebenz.org** `/api/stations?lat1=&lat2=&lon1=&lon2=` — база (полнее всех).
- **gdebenzi.ru** `/api/stations.php?bbox=lon1,lat1,lon2,lat2` — очередь в машинах, лимиты, свежесть (`markts`).
- **азсрадар.рф** `/api/stations?minLat=&maxLat=&minLng=&maxLng=` — очередь, статус по видам топлива.

Все три — открытые краудсорс-сервисы (данные отмечают сами водители). Наличия по
каждой АЗС нет в «официальном» открытом виде — точнее только у Яндекса, но у него
API закрыт. Поэтому данные народные и не гарантированно точные.

## Запуск локально

```bash
git clone https://github.com/hulapik13/info_day
cd info_day
python3 -m http.server 8000
# открыть http://127.0.0.1:8000/
```
(Карта и наличие работают сразу — читают `live.json`. Слой отметок друзей требует
своего проекта Firebase — вписать конфиг в `config.js`.)
